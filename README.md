# Neon Swarm

Ein kleines Arena-Survival-Spiel im Neon-Look. Eine einzige HTML-Datei, nichts zu installieren.

**Starten:** `index.html` im Browser öffnen (Doppelklick reicht).

## Steuerung
- **WASD / Pfeiltasten**: bewegen
- **Maus**: zielen (geschossen wird automatisch)
- **Leertaste**: Dash (kurz unverwundbar)
- **P**: Pause
- **1–3**: Upgrade beim Level-Up wählen

Sammle Kristalle, steig im Level auf, wähle Upgrades und überlebe den immer dichteren Schwarm. Alle 90 Sekunden kommt ein Boss. Dein Highscore wird im Browser gespeichert.
